# Разбор PDF расписания факультета

Эталон — `docs/reference/parse_schedule.py` (Python + pdfplumber). На сентябрьских PDF (4 курса)
он нашёл 10 из 10 пар преподавателя; результат сверен с картинками страниц.
В 0.4 этот алгоритм переносится на JavaScript (pdf.js) в `js/import/` за функцией `parsePdf(file)`.

## Что внутри PDF

- Таблица выгружена из Excel. Одна страница на курс, одна таблица.
- Текстовый слой есть, но порядок слов перемешан — читать текст подряд нельзя, только по координатам.
- **Границы ячеек нарисованы тонкими прямоугольниками** (ширина или высота < 2 pt). Это главный ключ.
- **Объединённая ячейка** (лекция на несколько групп) = место, где между колонками групп нет вертикальной
  границы. Других признаков объединения нет.
- Шапка: «1 курс (с 21.09.2026г. по 26.10.2026г.)» — срок действия; номера групп — трёхзначные числа
  над первой строкой пар.
- **КСРС** (день самостоятельной работы) — серый залитый прямоугольник (`non_stroking_color` 0.5–0.95)
  поверх всех групп на весь день.
- 6 дней × 9 пар = 54 строки. Время пары — в колонке слева в виде «08:00 - 09:20».

## Алгоритм

1. Собрать тонкие вертикальные отрезки (x, y-сверху, y-снизу) и тонкие горизонтальные (y, x0, x1).
2. Уникальные x вертикальных отрезков, по порядку: день | номер пары | время | группы… | номер пары.
   Границы колонок групп — `xs[3:-1]`, колонка времени — `(xs[2], xs[3])`.
3. Границы строк — горизонтальные отрезки, которые накрывают колонку времени.
   Строка пары — та, в чьей колонке времени есть «ЧЧ:ММ - ЧЧ:ММ». Проверка: строк ровно 54.
4. Номера групп — трёхзначные слова выше первой строки, по центру колонки.
5. Для каждой строки:
   - если её накрывает серый прямоугольник — это КСРС на всех группах;
   - иначе граница между соседними колонками групп **есть**, если вертикальный отрезок на этом x
     перекрывает больше половины высоты строки; нет отрезка — колонки объединены;
   - текст ячейки — слова, чей центр внутри ячейки, отсортированные по строке (y/4), потом по x.
6. Результат: `meta {course, start, end}`, `groups`, `cells [{day, pair, t0, t1, groups[], text, ksrs}]`.
7. Пары преподавателя — ячейки, в тексте которых есть его фамилия с инициалами.

## Перенос на pdf.js — на что обратить внимание

- Прямоугольники: `page.getOperatorList()` → операции `constructPath` с `rectangle`, плюс текущая матрица
  преобразования. Цвет заливки — из `setFillRGBColor` / `setFillGray` перед `fill`.
- Текст: `page.getTextContent()` → `items[].transform` (x = `transform[4]`, y = `transform[5]`), ширина `width`.
- **Система координат**: у PDF начало внизу слева, у pdfplumber — вверху слева.
  Перевести один раз: `top = pageHeight - y`.
- Слова в pdf.js могут приходить кусками или целыми строками — склеивать по координатам, как в шаге 5.
- Проверки из эталона (54 строки, найдены группы, найдена шапка со сроками) оставить: при сбое
  экран импорта показывает ошибку разбора, ручной ввод остаётся.

## Сопоставление с текущим расписанием

- Ключ импорта правила: `курс|группа|деньНедели|номерПары|предмет` (поле `importKey`).
- Новый PDF → добавилось / исчезло / сдвинулось. Ручная правка на том же месте → конфликт,
  пользователь выбирает: «Оставить мой перенос» или «Взять из PDF».
- Срок из шапки → `from` / `until` у правил курса.
