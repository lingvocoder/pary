# Мои пары

Расписание преподавателя: неделя пар, перенос пальцем, отмена, аудитории.
Чистые HTML, CSS и JavaScript, без сборки и библиотек. Работает без интернета (PWA).

## Как устроен код

```
index.html              разметка экрана
css/app.css             стили, светлая и тёмная тема
sw.js                   офлайн-режим
js/
  main.js               запуск: связывает слои, больше ничего
  config/               настройки: app.js (версия, ключи), university.js (звонки, курсы,
                        праздники), interface.js (времена и отступы)
  lang/ru.js            слова языка: дни, месяцы, склонение
  domain/               предметная область — чистые функции, без доступа к странице:
    dates.js            даты 'YYYY-MM-DD'
    lessons.js          занятия недели, кто в слоте, следующее занятие, фаза, праздник
    rules.js            что можно с занятием и что можно поставить в клетку
    changes.js          reduce() и все изменения данных
    forms.js            черновик новой пары, проверка формы, что изменилось
    texts.js            все составные тексты интерфейса
    hours.js, calendar-link.js, seed.js, migrate.js
  store/                state, dispatch(action), сохранение в телефон; настройки интерфейса
  ui/
    views/              представления: чистые функции «данные → HTML»
    week-screen.js      главный экран: следующая пара и сетка недели
    gestures.js         касания: тап, удержание и перетаскивание
    popover.js          подсказка по тапу на пару
    editor.js           редактор пары
    sheets.js, menu.js, hours.js   шторки, меню, часы за семестр
    geometry.js         где поставить подсказку — чистый расчёт
    layers.js           слои и кнопка «Назад»
    screen-state.js     какая неделя открыта и что на ней нарисовано
    dom.js, toast.js, icons.js
tests/                  зеркало js/: domain/, lang/, store/, ui/
scripts/check-standard.mjs   проверка стандарта: npm run check
```

Стандарт кода — [`docs/architecture.md`](docs/architecture.md): слои, имена, числа, функции.

Как идут данные: **касание → `dispatch(action)` → `reduce()` в модели → новое состояние → сохранение → перерисовка.**
Модель и интерфейс друг о друге не знают: интерфейс только читает состояние и отправляет действия.

## Запуск на компьютере

Модули браузера не работают при открытии файла двойным щелчком (`file://`), нужен локальный сервер:

- WebStorm: открыть `index.html` и нажать на значок браузера в правом верхнем углу редактора;
- или в Терминале, в папке проекта: `python3 -m http.server 8000` и открыть `http://localhost:8000`.

## Тесты

```
npm test
```

Проверяют модель: переносы «только эта дата / дальше», удаление, отмену, аудитории, миграцию старых данных.
Нужен Node.js 22 или новее. Зависимостей у приложения нет.

## Форматирование

```
npm install
npm run format
```

Prettier — единственная зависимость, только для разработки: выравнивает код по `.prettierrc`.
В приложение не попадает. Запускать перед каждым коммитом.

## Новый файл в проекте

Добавь его в список `FILES` в `sw.js` и поменяй там имя кэша (`pary-v0.3` → `pary-v0.4`),
иначе без интернета он не загрузится.
