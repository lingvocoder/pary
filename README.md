# Мои пары

Расписание преподавателя: неделя пар, перенос пальцем, отмена, аудитории.
Чистые HTML, CSS и JavaScript, без сборки и библиотек. Работает без интернета (PWA).

## Как устроен код

```
index.html            разметка экрана
css/app.css           стили, светлая и тёмная тема
js/
  config.js           настройки: сетка звонков, цвета, предметы
  dates.js            работа с датами 'YYYY-MM-DD'
  model.js            модель расписания — чистые функции, без доступа к странице
  store.js            состояние, dispatch(action), сохранение в телефон
  main.js             точка входа: связывает всё вместе
  ui/
    week.js           главный экран: следующая пара и сетка недели
    gestures.js       касания: тап, удержание и перетаскивание
    popover.js        подсказка по тапу на пару
    editor.js         редактор пары
    sheets.js         шторки снизу и вопрос «только эта дата или дальше»
    menu.js           меню и резервная копия
    calendar.js       ссылка в Google Календарь
    helpers.js        мелкие помощники
    state.js          какая неделя открыта
tests/model.test.js   тесты модели
sw.js                 офлайн-режим
```

Как идут данные: **касание → `dispatch(action)` → `reduce()` в модели → новое состояние → сохранение → перерисовка.**
Модель и интерфейс друг о друге не знают: интерфейс только читает состояние и отправляет действия.

## Запуск на компьютере

Модули браузера не работают при открытии файла двойным щелчком (`file://`), нужен локальный сервер:

- WebStorm: открыть `index.html` и нажать на значок браузера в правом верхнем углу редактора;
- или в Терминале, в папке проекта: `python3 -m http.server 8000` и открыть `http://localhost:8000`.

## Тесты

```
npm test
```

Проверяют модель: переносы «только эта дата / дальше», удаление, отмену, аудитории, миграцию старых данных.
Нужен Node.js 22 или новее. Зависимостей у приложения нет.

## Форматирование

```
npm install
npm run format
```

Prettier — единственная зависимость, только для разработки: выравнивает код по `.prettierrc`.
В приложение не попадает. Запускать перед каждым коммитом.

## Новый файл в проекте

Добавь его в список `FILES` в `sw.js` и поменяй там имя кэша (`pary-v0.3` → `pary-v0.4`),
иначе без интернета он не загрузится.
